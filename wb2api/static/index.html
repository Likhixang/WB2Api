映射 JSON

保存前在本地解析 JSON 并检查字段类型；只有点击“保存配置”才会提交。重新读取会替换编辑器内容。

字段参考

event_type_path
事件类型的字段路径。
turn_id_path / thread_id_path
轮次标识与会话标识的字段路径。
text_path
文本内容的字段路径。
delta_events / done_events / error_events
分别填写文本、结束、错误事件的真实类型名，值为字符串数组。没有样本时保持空数组，不猜测。
mode
delta 表示增量文本；snapshot 表示完整快照。

字段路径的结构示例：data.text（仅说明点分路径形式，不代表上游实际字段）。所有路径与事件名以真实流量为准。

接入前确认

  • 至少一个启用且凭据就绪的账户。

  • 客户端能够访问此服务，生产环境使用 HTTPS。
